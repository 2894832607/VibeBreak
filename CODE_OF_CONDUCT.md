# Code of Conduct

VibeBreak contributors are expected to communicate directly and respectfully.

Harassment, discrimination, personal attacks, and disclosure of another
person's private information are not acceptable in project spaces. Technical
disagreement should stay focused on observable behavior, contracts, tradeoffs,
and evidence.

Maintainers may edit or remove contributions and participation that violate
these expectations. Serious concerns should be reported privately to the
repository maintainer.
